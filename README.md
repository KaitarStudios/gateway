# Für Exodus
A web game that will feature spacecraft flying across planets,
players can customize their own spacecraft and encounter new scenarios.
## Technologies
- Three.JS
- Websocket
- Apache
- phpMyAdmin
## Features
- Backend API for multiplayer and Saving
- Customizable ship designs
## Vision
This project was an spiritual successor to the ![Kaitar Labs](https://github.com/KaitarStudios/Kaitar_Studios_Export) Space program.
Continuing to expand on the space exploration aspects to achieve a player-led storyline. 
This project was moved off a game platform, remade in a local server, before finally moving the client infrastructure online.
## Execution
- Download ![XAMPP server](https://www.apachefriends.org/)
- Copy files to htdocs
- Start apache server
- open ![XAMPP server](http://localhost/)
